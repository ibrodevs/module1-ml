# Проект 1: риск инсульта

**Модуль:** Машинное обучение, проект 1

**Данные:** `healthcare-dataset-stroke-data.csv` — 5 110 пациентов

**Цель:** исследовать, как модели классификации выявляют пациентов с зарегистрированным инсультом (`stroke = 1`).

> Учебный проект. Модель не предназначена для медицинской диагностики и не заменяет врача.

## Структура репозитория

```text
module1-ml/
├── data/healthcare-dataset-stroke-data.csv
```

## Запуск

Требуется Python 3.10+.

```bash
python -m pip install -r requirements.txt
python src/stroke_project.py --variant all
```

Каждый вариант можно запустить отдельно: `--variant basic`, `--variant main` или `--variant advanced`. Метрики сохраняются в `results/`.

## Данные и подготовка

В таблице 5 110 строк и 12 колонок: идентификатор, демографические и медицинские признаки и целевая переменная `stroke`. Целевой класс сильно несбалансирован: 4 861 наблюдение без инсульта (95,1%) и 249 с инсультом (4,9%). В `bmi` 201 пропуск. Колонка `id` исключается из признаков. Числовые пропуски заполняются медианой, категориальные — наиболее частым значением; категории кодируются One-Hot Encoding, числа масштабируются. Все шаги подготовки входят в sklearn Pipeline, поэтому статистики заполнения и масштабирования обучаются только на тренировочных данных.

## Варианты задания

### A. Базовый

- Загрузка CSV, обзор размеров, пропусков и долей классов.
- Разбиение 80/20 со стратификацией и `random_state=42`.
- Pipeline: заполнение пропусков, One-Hot Encoding, StandardScaler, LogisticRegression.
- Метрики на отложенной части: accuracy, confusion matrix, precision/recall/F1/F2, ROC-AUC и Average Precision.

Результат при стандартном пороге 0,5: accuracy **95,2%**, recall класса инсульта **2,0%** (1 из 50). Высокая accuracy здесь вводит в заблуждение: модель почти всегда выбирает большинство.

### B. Основной

- Проверка дисбаланса и пропусков.
- Две модели в одинаковом Pipeline: Logistic Regression и Random Forest с `class_weight="balanced"`.
- Выбор порога по F2 на out-of-fold вероятностях тренировочной части с `StratifiedKFold(5)`; тестовая часть при подборе не используется.
- Сравнение на одном отложенном наборе по метрикам заказчика. Для предварительного отбора пациентов важен recall, но вместе с ним показываем precision и количество ложных срабатываний.

На тестовой части лучший F2 у Logistic Regression: порог **0,070**, recall **78%** (39/50), precision **16,9%**, F2 **0,452**. Это означает много ложных тревог (192), поэтому результат требует оценки специалистами и согласования пропускной способности клиники.

### C. Продвинутый

- Разобраны редкость положительного класса, пропуски и риск утечки данных; `id` исключён, препроцессинг обучается внутри Pipeline.
- Сравнены два способа учитывать дисбаланс: стандартная Logistic Regression и `class_weight="balanced"`.
- Для взвешенной модели порог также подобран по F2 на out-of-fold обучающих прогнозах.
- Ошибки представлены через TP/FP/FN/TN. Ограничение: один случайный holdout и всего 50 положительных примеров в нём; результаты нестабильны, для надёжных выводов нужны внешняя проверка и клиническая валидация.

При взвешенной модели с подобранным порогом recall **80%** (40/50), precision **15,6%**, F2 **0,438**. Снижение числа пропусков оплачивается большим числом ложных тревог (217). Выбор порога зависит от ресурсов и цены ошибок, а не только от качества модели.

## Метрики и смысл ошибок

Матрица ошибок записана относительно класса `stroke=1`:

- **TP** — пациент с инсультом правильно отмечен как положительный;
- **FN** — случай инсульта пропущен;
- **FP** — пациент без инсульта ошибочно направлен на дополнительное обследование;
- **TN** — пациент без инсульта правильно отнесён к отрицательному классу.

Поскольку пропуск пациента высокого риска может быть особенно нежелателен, для сравнения порогов использован F2, который сильнее учитывает recall. Метрика не задаёт клинический порог автоматически: финальное решение должно учитывать стоимость обследований и доступную пропускную способность.

## Вывод

Одна accuracy не подходит для оценки редкого события: при пороге 0,5 модель пропускает почти все случаи инсульта. Подбор порога по тренировочным кросс-валидационным прогнозам повышает чувствительность, но приводит к множеству ложных тревог. На этом наборе Logistic Regression дала лучший F2 среди проверенных подходов. Это учебный анализ ассоциаций, а не инструмент постановки диагноза или прогноза для реальных пациентов.
