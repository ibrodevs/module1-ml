# Results

Results are reproducibly generated by:

```bash
python src/stroke_project.py --variant all
```

- `eda_report.json`: missing values, proportions, outlier candidates, and data-quality notes.
- `basic_metrics.json`: baseline Logistic Regression at threshold 0.5.
- `main_metrics.json`: two models, thresholds selected on training OOF predictions.
- `model_selection.json`: model selected using **training OOF F2**, without using holdout metrics.
- `advanced_metrics.json`: class-weight and decision-threshold ablations.
- `subgroup_errors.csv`: TP, FP, FN, TN and recall/precision by patient subgroup.

The committed baseline JSON files originate from an earlier run. Run the command
to regenerate the expanded results after checking out this repository.
These are educational classification results, not validated clinical risk scores.
